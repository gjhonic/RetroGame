# Правила: git

## Именование веток

Формат: `<номер_задачи>_<модуль>_<что_изменено_1-2_словами>`

Пример: `1_project_init`

## Pull Request

- Слияние в `main` только через PR: обязателен зелёный CI и минимум 1 апрув
  (см. защиту ветки `main` на GitHub).
- Прямой push в `main` запрещён всем, включая админов.
