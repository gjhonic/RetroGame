# Правила: git

## Ветки

Формат: `<номер_задачи>_<модуль>_<что_изменено_1-2_словами>`, пример `1_project_init`.

## Pull Request

Слияние в `main` только через PR: зелёный CI + минимум 1 апрув. Прямой push в `main` запрещён всем.

Имя PR: `RG-<номер> <Модуль>. <Краткое описание>`, пример `RG-1 Project. Инициализация проекта, статический анализ, CI`.

## Коммиты

Формат: `RG-<номер>: <описание в повелительном наклонении>`, примеры: `RG-12: добавлена форма логина`, `RG-1: инициализация Symfony-проекта`. Без привязки к задаче — можно без префикса, но лучше избегать.
