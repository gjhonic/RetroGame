# Правила: git

## Именование веток

Формат: `<номер_задачи>_<модуль>_<что_изменено_1-2_словами>`

Пример: `1_project_init`

## Pull Request

- Слияние в `main` только через PR: обязателен зелёный CI и минимум 1 апрув
  (см. защиту ветки `main` на GitHub).
- Прямой push в `main` запрещён всем, включая админов.

### Именование PR

Формат: `RG-<номер_задачи> <Название модуля>. <Краткое описание что сделано>`

Пример: `RG-1 Project. Инициализация проекта, статический анализ, CI`

## Коммиты

Формат: `RG-<номер_задачи>: <краткое описание в повелительном наклонении>`

Примеры:
- `RG-12: добавлена форма логина`
- `RG-1: инициализация Symfony-проекта`

Если коммит не привязан к задаче — можно без префикса, но лучше избегать
такого на постоянной основе.
