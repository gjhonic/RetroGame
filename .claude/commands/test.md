---
description: Запустить make test для затронутых директорий и починить найденные ошибки
---

Определи затронутые изменениями директории (`git status`/`git diff` относительно base-ветки, либо
аргумент команды `$ARGUMENTS`, если он задан — путь вида `src/Service/Steam`).

1. Запусти `make test-phpstan DIR=<путь>` и `make test-phpcs DIR=<путь>` для затронутых директорий
   (по умолчанию DIR — `src tests`, см. `Makefile`).
2. Если PHPCS находит автоисправимые нарушения — сначала `make fix-cs DIR=<путь>`, затем перепроверь.
3. Если тестов/файлов достаточно мало — прогони `make test-unit` целиком (PHPUnit не поддерживает
   точечный DIR через Makefile).
4. Почини все найденные ошибки статического анализа, стиля и упавшие тесты; для новых тестов свериться
   с `.claude/rules/tests.md` (единый файл тестов юнит-тесты без БД, `TestCases.md` рядом).
5. Прогони проверки ещё раз, чтобы убедиться, что всё зелёное, прежде чем считать задачу завершённой.
