нового кейса — дописывайте сюда строку с методом, где он проверяется.

## OurGameShow.spec.js

Страница только для просмотра (без редактирования) — `assets/vue/Admin/OurGameEdit.vue`
отвечает за форму, эта страница показывает баннер/обложку (обрезаны по
шаблону `.our-game-banner`/`.our-game-cover`, см. `assets/styles/admin/base.css`),
системную информацию, описание и ссылки на скачивание, плюс действия
"Редактировать"/"Удалить игру".

| Кейс | Метод теста |
|---|---|
| Запрос игры, рендер баннера/обложки/системной инфы/описания, `document.title` | `запрашивает игру и рендерит баннер/обложку/системную инфу/описание` |
| Состояние ошибки при неудачном запросе | `показывает ошибку при неудачном запросе` |
| Ссылка "Редактировать" ведёт на `/admin/our-games/{id}/edit` | `ссылка "Редактировать" ведёт на страницу редактирования` |
| Блок "Ссылки на скачивание" — подпись платформы + URL | `показывает ссылку на скачивание с подписью платформы` |
| Блок "Посты" — запрос `filters[game]={id}` к `/api/admin/our-game-posts`, рендер строк | `запрашивает посты по игре и рендерит их в таблице` |
| Блок "Посты" — пустое состояние | `показывает сообщение, если постов ещё нет` |
| Кнопка "Добавить пост" ведёт на `/admin/our-game-posts/new?gameId={id}` | `кнопка "Добавить пост" ведёт на страницу создания с предзаполненной игрой` |
| Удаление игры: подтверждение + переход к списку | `запрашивает подтверждение и переходит к списку после удаления` |
| Отмена подтверждения — запрос на удаление не отправляется | `ничего не делает, если пользователь отменил подтверждение` |

## OurGameEdit.spec.js

Две формы на странице (редактирование полей и добавление ссылки на скачивание)
различаются классами `our-game-form`/`our-game-download-link-form` — иначе
`wrapper.get('form')` неоднозначен (в этом окружении `findAll('form')` не
гарантирует порядок DOM, проверено отдельно через `document.querySelectorAll`).
Удаление игры перенесено на `OurGameShow.spec.js` — здесь только форма и картинки.

| Кейс | Метод теста |
|---|---|
| Запрос игры и жанров, заполнение формы, ссылка "Просмотр", `document.title` | `запрашивает игру и жанры, заполняет форму, ссылка на просмотр ведёт на страницу игры` |
| Состояние ошибки при неудачном запросе | `показывает ошибку при неудачном запросе` |
| `PATCH` с полями формы, сообщение «Сохранено» | `отправляет PATCH с полями формы и показывает «Сохранено»` |
| `422` от API — ошибки валидации отображаются без падения | `показывает ошибки валидации без падения` |
| Загрузка обложки (`POST .../cover`) обновляет превью (класс `.our-game-cover`) | `загружает обложку и обновляет превью` |
| `422` от API при загрузке баннера (например, файл превышает лимит) — показана ошибка из `errors.file` | `показывает ошибку сервера, если загрузка баннера не удалась (например, файл слишком большой)` |
| Удаление скриншота отправляет `DELETE` с `url` в теле | `удаляет скриншот с указанным url` |
| Добавление ссылки на скачивание по сабмиту формы | `добавляет ссылку на скачивание по сабмиту формы` |
| Удаление ссылки на скачивание после подтверждения (`window.confirm`) | `удаляет ссылку на скачивание после подтверждения` |

## Dashboard.spec.js

Графики (`Bar`/`Doughnut` из `vue-chartjs`) требуют `canvas.getContext('2d')`,
которого нет в jsdom — модуль `vue-chartjs` мокается через `vi.mock` именован-
ными заглушками, данные проверяются через их пропы `data`.

| Кейс | Метод теста |
|---|---|
| Запрос `/api/admin/stats`, рендер карточек статистики (игры/жанры/разработчики/издатели) | `запрашивает /api/admin/stats и рендерит карточки статистики` |
| Спиннер во время загрузки | `показывает спиннер во время загрузки` |
| Состояние ошибки при неудачном запросе | `показывает состояние ошибки при неудачном запросе` |
