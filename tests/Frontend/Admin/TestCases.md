# Тест-кейсы: Vue-компоненты админки

Список проверяемых сценариев для `assets/vue/Admin/`. При добавлении
нового кейса — дописывайте сюда строку с методом, где он проверяется.

## Dashboard.spec.js

Графики (`Bar`/`Doughnut` из `vue-chartjs`) требуют `canvas.getContext('2d')`,
которого нет в jsdom — модуль `vue-chartjs` мокается через `vi.mock` именован-
ными заглушками, данные проверяются через их пропы `data`.

| Кейс | Метод теста |
|---|---|
| Запрос `/api/admin/stats`, рендер карточек статистики (игры/жанры/разработчики/издатели) | `запрашивает /api/admin/stats и рендерит карточки статистики` |
| Спиннер во время загрузки | `показывает спиннер во время загрузки` |
| Состояние ошибки при неудачном запросе | `показывает состояние ошибки при неудачном запросе` |
| В график «Игры по годам выхода» передаются подписи/значения из `gamesByYear` | `передаёт в график «Игры по годам выхода» подписи и значения из gamesByYear` |
| В график «Топ жанров» передаются подписи/значения из `topGenres` | `передаёт в график «Топ жанров» подписи и значения из topGenres` |
| В график распределения оценок передаются подписи/значения из `scoreDistribution` | `передаёт в график распределения оценок подписи и значения из scoreDistribution` |
