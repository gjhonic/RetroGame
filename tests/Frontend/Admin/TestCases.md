# Тест-кейсы: Vue-компоненты админки

Список проверяемых сценариев для `assets/vue/Admin/`. При добавлении
нового кейса — дописывайте сюда строку с методом, где он проверяется.

## GameList.spec.js

| Кейс | Метод теста |
|---|---|
| Запрос первой страницы со значениями по умолчанию, рендер строки | `запрашивает первую страницу со значениями по умолчанию и рендерит строку` |
| Состояние ошибки при неудачном запросе | `показывает состояние ошибки при неудачном запросе` |
| Пустой результат | `показывает сообщение о пустом результате` |
| Жанры рендерятся как отдельные бейджи-пилюли | `рендерит жанры в виде отдельных пилюль-бейджей` |
| Ввод текста в фильтр не отправляет запрос | `не отправляет запрос при простом вводе текста в фильтр` |
| Клик «Применить» отправляет запрос с фильтром | `отправляет запрос с фильтром по клику на «Применить»` |
| Enter в поле фильтра отправляет запрос | `отправляет запрос с фильтром по Enter в поле ввода` |
| Кнопка «✕» сбрасывает и применяет фильтр | `сбрасывает фильтр и применяет его по клику на «✕»` |
| Фильтры разработчика/издателя/жанра маппятся на серверные имена полей | `маппит фильтр разработчика/издателя/жанра на серверные имена полей` |
| Клик по заголовку колонки — запрос с sortBy/sortDir | `запрашивает страницу заново с sortBy/sortDir по клику на заголовок колонки` |
| Повторный клик переключает направление сортировки | `переключает направление сортировки по повторному клику` |
| Колонка жанров не кликабельна для сортировки | `не даёт кликом по жанрам инициировать сортировку` |
| Снятие галочки в меню «Столбцы» скрывает колонку | `скрывает колонку по снятию галочки в меню «Столбцы»` |
| Переход на следующую страницу запрашивает её у API | `переходит на следующую страницу и запрашивает её у API` |
| Смена размера страницы сбрасывает на страницу 1 и меняет perPage | `сбрасывает на первую страницу и меняет perPage при смене размера страницы` |

## GenreList.spec.js / DeveloperList.spec.js / PublisherList.spec.js

`templates/admin/genre|developer|publisher/index.html.twig`). Сейчас у
каждого только `name`/`gamesCount` и набор кейсов идентичен во всех трёх
файлах — компоненты сознательно не объединены в один общий (в отличие от
раннего варианта `NamedEntityList.vue`), так как ожидается, что у каждого
справочника со временем появятся свои поля.

| Кейс | Метод теста |
|---|---|
| Запрос своего API-эндпоинта со значениями по умолчанию, рендер строки | `запрашивает /api/admin/... со значениями по умолчанию и рендерит строку` |
| Состояние ошибки при неудачном запросе | `показывает состояние ошибки при неудачном запросе` |
| Пустой результат | `показывает сообщение о пустом результате` |
| Ввод текста в фильтр не отправляет запрос | `не отправляет запрос при простом вводе текста` |
| Клик «Применить» отправляет запрос с фильтром | `отправляет запрос с фильтром по клику на «Применить»` |
| Enter в поле фильтра отправляет запрос | `отправляет запрос по Enter` |
| Кнопка «✕» сбрасывает и применяет фильтр | `сбрасывает и применяет фильтр по клику на «✕»` |
| Клик по заголовку «Количество игр» — запрос с sortBy/sortDir | `запрашивает страницу заново с sortBy/sortDir по клику на заголовок «Количество игр»` |
| Переход на следующую страницу запрашивает её у API | `переходит на следующую страницу и запрашивает её у API` |
