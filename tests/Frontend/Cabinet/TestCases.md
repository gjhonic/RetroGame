# Тест-кейсы: Vue-компоненты личного кабинета

Список проверяемых сценариев для `assets/vue/Cabinet/`. При добавлении
нового кейса — дописывайте сюда строку с методом, где он проверяется.

## AvatarUpload.spec.js

| Кейс | Метод теста |
|---|---|
| Аватар не задан → показывается инициал письма | `показывает инициал письма, когда аватар не задан` |
| Аватар задан → `<img>` с ведущим слэшем в `src` | `показывает текущий аватар с ведущим слэшем` |
| Подходящий файл (100×100 JPG) → POST-запрос multipart, сообщение об успехе | `загружает подходящий файл и показывает сообщение об успехе` |
| Файл больше 400×400px → запрос не отправляется, показана ошибка | `отклоняет файл, превышающий 400×400px, не отправляя запрос` |
| Неподдерживаемый MIME-тип → ошибка без похода в Image/fetch | `отклоняет неподдерживаемый формат файла без похода в Image/fetch` |
| Ответ сервера 422 → показана ошибка из `errors.file` | `показывает ошибку сервера при 422` |
| Сетевой сбой при загрузке → общая ошибка | `показывает общую ошибку при сетевом сбое во время загрузки` |

## PasswordChangeForm.spec.js

| Кейс | Метод теста |
|---|---|
| Валидная форма → PATCH `/api/cabinet/profile/password` с текущим/новым паролем | `отправляет текущий и новый пароль на PATCH /api/cabinet/profile/password` |
| Новый пароль и подтверждение не совпадают → запрос не отправляется | `не отправляет запрос, если новый пароль и подтверждение не совпадают` |
| Ответ 422 → показаны ошибки по полям | `показывает ошибки по полям при 422` |
| Сетевой сбой → общая ошибка | `показывает общую ошибку при сетевом сбое` |

## GameCatalog.spec.js

| Кейс | Метод теста |
|---|---|
| Загрузка первой страницы, ссылки карточек ведут на `/cabinet/games/...` | `загружает первую страницу и рендерит карточки игр со ссылками на /cabinet/games/...` |
| Пустое состояние без активных фильтров | `показывает пустое состояние без игр (без активных фильтров)` |
| Состояние ошибки | `показывает ошибку при неудачном запросе` |
| Поиск по названию применяется через debounce (400мс) | `дебаунсит поиск по названию` |
| Фильтр по жанру уходит в запрос, страница сбрасывается на первую | `применяет фильтр по жанру и сбрасывает страницу на первую` |

## GameDetail.spec.js

| Кейс | Метод теста |
|---|---|
| Запрос игры по slug, рендер деталей | `запрашивает игру по slug и рендерит подробности` |
| Состояние ошибки загрузки игры | `показывает ошибку, если игра не найдена` |
| Список тэйков игры загружается через `GET /api/takes?filters[game]=<id>` и рендерится | `загружает и показывает список тэйков игры` |
| Пустое состояние, если тэйков нет | `показывает пустое состояние, если тэйков ещё нет` |
| Кнопка "Добавить тэйк" открывает модалку `TakeCreateModal` | `кнопка "Добавить тэйк" открывает модалку создания` |
| Событие `created` от модалки добавляет тэйк в начало списка и закрывает модалку | `добавляет созданный тэйк в начало списка и закрывает модалку` |

## TakeCreateModal.spec.js

| Кейс | Метод теста |
|---|---|
| Валидная отправка → `POST /api/cabinet/takes`, эмит `created` при 201 | `отправляет текст на POST /api/cabinet/takes и эмитит created при 201` |
| Ответ 422 → показаны ошибки по полям, `created` не эмитится | `показывает ошибки по полям при 422` |
| Сетевой сбой → общая ошибка | `показывает общую ошибку при сетевом сбое` |
| Крестик/кнопка "Отмена"/клик по оверлею → эмит `close` | `эмитит close по клику на крестик, кнопку "Отмена" и клику по оверлею` |
| Клавиша Escape → эмит `close` | `эмитит close по клавише Escape` |
