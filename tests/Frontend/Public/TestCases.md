# Тест-кейсы: Vue-компоненты публичных страниц

Список проверяемых сценариев для `assets/vue/Public/`. При добавлении
нового кейса — дописывайте сюда строку с методом, где он проверяется.

## GameCatalog.spec.js

| Кейс | Метод теста |
|---|---|
| Загрузка первой страницы, рендер карточек (включая бейдж популярности) | `загружает первую страницу и рендерит карточки игр` |
| Номер страницы читается из `?page=` при монтировании | `читает номер страницы из query-параметра ?page= при монтировании` |
| Пустое состояние без активных фильтров | `показывает пустое состояние без игр (без активных фильтров)` |
| Состояние ошибки | `показывает ошибку при неудачном запросе` |
| Переход на следующую страницу обновляет URL | `переходит на следующую страницу и обновляет URL` |
| Пагинация не рендерится при totalPages=1 | `не даёт уйти на страницу за пределами диапазона` |
| ≤7 страниц: кнопки всех страниц подряд, без многоточия | `при малом числе страниц показывает кнопки всех страниц без многоточия` |
| Много страниц, текущая в начале: окно 1–5 + многоточие + последняя | `при большом числе страниц показывает окно вокруг текущей с многоточием до последней` |
| Текущая страница в середине диапазона: многоточие с обеих сторон окна, активная кнопка подсвечена | `при странице в середине диапазона показывает многоточия с обеих сторон` |
| Клик по номеру страницы в пагинации загружает эту страницу | `клик по номеру страницы переходит на неё` |
| Справочник фильтров (`/api/games/filters`) заполняет селекты жанров/платформ | `заполняет селекты жанров/платформ из /api/games/filters` |
| Фильтр по жанру уходит в запрос обрезанным, страница сбрасывается на первую | `применяет фильтр по жанру и сбрасывает страницу на первую` |
| Поиск по названию применяется через debounce (400мс) | `дебаунсит поиск по названию` |
| Кнопка "Сбросить" видна только при активных фильтрах/нестандартной сортировке и очищает их | `кнопка "Сбросить" появляется при активных фильтрах и очищает их` |

## GameDetail.spec.js

| Кейс | Метод теста |
|---|---|
| Запрос игры по slug, рендер деталей, `document.title` | `запрашивает игру по slug и рендерит подробности` |
| Состояние ошибки | `показывает ошибку, если игра не найдена` |
| Клик по скриншоту открывает лайтбокс с нужным изображением | `открывает лайтбокс по клику на скриншот и показывает нужное изображение` |
| Кнопки лайтбокса листают вперёд/назад по кругу | `листает скриншоты вперёд и назад по кнопкам лайтбокса` |
| Крестик закрывает лайтбокс | `закрывает лайтбокс по клику на крестик` |
| Escape закрывает, стрелки листают скриншоты | `закрывает лайтбокс по клавише Escape и листает по стрелкам` |

## RegistrationForm.spec.js

| Кейс | Метод теста |
|---|---|
| Успешная регистрация (201): запрос уходит на `/api/register`, показывается экран успеха со ссылкой на вход | `отправляет данные формы на /api/register и показывает успех при 201` |
| Ошибки валидации (422): показываются под соответствующими полями | `показывает ошибки по полям при 422` |
| Email уже занят (409): показывается сообщение о конфликте | `показывает сообщение о занятом email при 409` |
| Сетевой сбой: показывается общая ошибка | `показывает общую ошибку при сетевом сбое` |
